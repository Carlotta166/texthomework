## 归档约定

每讲一个文件夹，命名格式统一为 `第N讲-主题简称`，例如：

- `第1讲-课程导言与分词`
- `第2讲-词频统计与分析`
- `第3讲-词云与可视化`

每个讲次目录下放：该讲的全部 notebook、运行所依赖的数据文件（如 `dict.txt`、`stop_words.txt`），以及一份 `README.md` 说明本次作业完成情况。新增讲次时，同步更新上表的「作业清单」。
